## Step A — Generate model migration on existing Windows machine

After pulling the reviewed GitHub branch and confirming no local changes:

```powershell
$ErrorActionPreference = 'Stop'
cd D:\GitHub\YangSpaceApp
git pull --ff-only origin feat/yangspace-v2-foundation-20261108
$Sha = (git rev-parse HEAD).Trim()
.\scripts\New-InitialMigration-Local.ps1 -CommitSha $Sha
```

The script refuses an unexpected SHA, branch, dirty worktree or pre-existing `apps/api/Migrations`. It installs **only the pinned local EF tool**, restores/builds API code, runs `dotnet ef migrations add InitialDirectorySchema`, rebuilds, asserts no pending model changes, and emits EF SQL from migration `0` in ignored evidence. It verifies Identity/Directory tables exist in generated SQL and rejects `DROP` statements.

Expected:
```text
MIGRATION_SCAFFOLD=PASS
MODEL_SNAPSHOT_DIFF=NONE
GENERATED_MIGRATIONS=D:\GitHub\YangSpaceApp\apps\api\Migrations
EVIDENCE_DIR=D:\GitHub\YangSpaceApp\logs\yangspace\migration-scaffold\...
```

**No `database update`, live DB connection, SQL apply, HTTP port, PVE/CT operation or automatic Git commit/push occurs.** Existing `5090`/Angular `4200` services are not stopped or addressed.
