# H06.2-C — Public Directory Journeys

## Implementation baseline

The existing public directory remains anonymous and uses the existing /api/v1/homepage and /api/v1/locations contracts. Search is debounced; category and neighborhood filters compose into the same query; pagination uses the selected page; reset clears the active query/filter state. A newer search invalidates and unsubscribes an older request before the debounce window completes, preventing stale results from replacing the visitor's latest intent.

The homepage highlights retain the H06.2-A three-state contract:
- Loading is not represented as an empty result.
- A successful empty list is a genuine empty state.
- A failed bootstrap clears stale highlight payloads and presents unavailable/retry feedback.
- Retrying highlights while a search/filter/page is active does not replace the directory state.

No API/backend contract or production behavior changed.
